NeuroNote Help Guide

📘 Books

Use + New Book to create books.

Each book contains chapters and pages.

📂 Chapters

Click + Chapter to create chapters.

Chapters organize pages.

📄 Pages

Click a page to open it.

Everything is auto-saved.

✏ Drawing Tool

Use the right toolbar pencil icon.

Draw using Pen, Eraser, Line, Rectangle, and Circle.

📷 Images

Use the image button to insert images.

You can also drag and drop images.

📊 Tables

Use the table button to create editable tables.

🤖 AI Sidebar

Click the AI button to open Neuro AI.

Ask questions, summarize notes, or generate quizzes.

🎨 Themes

Open settings and select themes.

⌨ Shortcuts

Press CTRL + K to open Command Palette.

Type / inside editor to open Slash Commands.

💾 Export

Export books as PDF, DOCX, or TXT.

⚡ Auto Save

Notes save automatically after editing.
